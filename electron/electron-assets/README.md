# App Icons

## Building Icons

To generate all app icons from a source image:

1. Place your source image as `icon.png`, `icon.jpg`, or `icon.jpeg` in the `electron/electron-assets/` directory
2. Run the build script:
   ```bash
   bun run build:icons
   ```
   or
   ```bash
   npm run build:icons
   ```

## Output Files

The script generates the following files in the `icons/` directory:

- **PNG icons**: Various sizes (16x16, 32x32, 48x48, 64x64, 128x128, 256x256, 512x512)
- **icon.png**: Main icon file (512x512) for Linux and general use
- **icon.icns**: macOS icon file (generated on macOS using iconutil, or PNG fallback on other platforms)
- **icon.ico**: Windows icon file (requires manual conversion or external tools)

## Manual ICO Generation

If you need to create a proper `.ico` file for Windows, you can:

1. Use online tools like [icoconvert.com](https://icoconvert.com)
2. Use ImageMagick: `convert icon-256x256.png icon.ico`
3. Use the PNG files generated by the build script with any ICO converter
